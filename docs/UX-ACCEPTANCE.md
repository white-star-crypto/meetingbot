# UX acceptance checklist

面向「陌生人第一次使用、并且要长期使用」的可复现验收清单。
这份文档区分**已自动验证**和**必须人工点击**的部分，不把静态检查冒充真实走查。

## 0. 怎么开始

```bash
npm test                                   # 5 组测试，含静态 UI 契约
npm run demo                               # 离线 mock 会议，验证流水线产出
npm run app                                # Electron 桌面窗口（需要本机 electron）
# 或只用浏览器面板：
node bin/meetingbot.mjs panel --config meeting.config.local.json --port 4318
# 打开 http://127.0.0.1:4318
```

真实模型会议需要可用的 API Key：在「设置 → 模型 → 添加模型」里填，或按
[README](../README.md) 写配置文件。没有密钥时，用 `npm run demo` 验证流水线、
用面板里的「示例演示」验证界面；示例演示的文案明确标注为预置样本，不算真实会议。

## 2. 真实功能路径（每项至少走一次）

按顺序点击，记录「通过 / 失败 + 现象」：

1. **首次打开**：5 秒内是否能看出这是「多个模型开会出结论」；三步引导可跳过、可关闭；关掉引导后欢迎卡不叠两张。
2. **配置密钥**：设置 → 模型 → 添加模型 → 测试连接 → 保存。刷新后密钥不回显明文，但会议能读到；自定义端点只测连接 + 存密钥，界面明确写「计划中」。
3. **合议会议**：侧栏「合议」→ 新会议 → 写任务 → 发起；观察状态文案从「启动中」到「已生成决议」；决策书页有采纳 / 否决 / 风险 / 下一步 / token 用量。
4. **分工 / 点将**：切换两个模式，确认会议结果里的分工是可读的，不是把同一段文字换个标题。
5. **失败态**：故意填错 key 或断网再发起。必须看到「失败阶段 / 失败模型 / 参议阵容 / 原因与下一步」，且「重试」「换模型再试」「检查 API Key」「复制错误」四个按钮都做实事。
6. **私聊**：选模型与推理档 → 发送 → 看工具轨迹 → 上下文 chip → 提问弹窗 → 群修 / 私修按钮能带上下文回到会议。
7. **插件市场**：搜索 → 分类 → 翻页 → 详情 → 复制安装命令（有提示且会复位）→「发送给 Agent」。切到私聊后必须能看到「已预填、尚未发送」，且不会自动发出。
8. **权限**：四档切换，确认文案说清「会问 / 不会问」；免责协议只在高风险模式出现；审计日志能打开并有记录。默认始终是只读。
9. **上下文压缩**：私聊多轮后切换「压缩 / 缓存摘要 / 仅当前」，观察上下文 chip 与后续回复是否按策略变化。
10. **审图回退**：触发一次审图不通过，确认主 Bot 的重新分工可读、「下一轮」按钮明确，且**没有**回滚本机文件。
11. **会话菜单**：重命名 / 置顶 / 归档 / 分叉 / 移动 / 删除 / 批量操作逐项点；删除后到「归档」里恢复；「彻底删除」要出现二次确认。
12. **设置**：六组逐组改一项，确认立刻生效；点单项「↺ 恢复默认」只重置该项；导出设置再导入，确认不含 API Key；备份 / 恢复、清空缓存、打开数据目录都要真做事。

## 3. 第三轮新增的验收点（2026-11-08）

这些是本轮修复过的行为，逐条确认它们没有回退：

1. **开会前的补充约束**：在会议没开始时往输入框写一句话 → 输入区上方出现「补充约束」chip，按钮文案是「加入约束」→ 发起会议 → 决策书里能看到这条约束生效。失败重试时约束仍在。
2. **会话不被另一个实例抹掉**：同时开两个面板实例，在其中一个里新建会话，另一个刷新后仍能看到。
3. **模型面板不压输入框**：打开「模型」面板，输入框仍完全可见可输入（1280×820 与 960×620 都查）。
4. **上下文轨道不撒谎**：任意条数的消息，提示里只出现「历史消息 / 当前位置」，不出现「压缩上下文」。
5. **备份真的带阵容**：导出设置 → 打开 JSON → 有 `roster` 且含 `selected` / `thinking` / `pinnedModels`；导入后阵容与置顶恢复。
6. **深色主题可读**：顶部「只读」徽标是透明底、浅色字；侧栏选中项是亮蓝字；整体无浅底浅字。
7. **插件卡片不破版**：18 张卡片介绍文字都完整停在三行并带省略号，不压到按钮。
8. **窄窗口侧栏真的收缩**：960×620 下侧栏宽度 = 200px（设置里写的「窄屏自动收缩」这次是真的）。
9. **侧栏不横向滚动**：会话标题过长时显示「…」，侧栏底部没有横向滚动条。
10. **导航只高亮一个**：在私聊 / 插件 / 工具页，顶部状态角标分别显示当前视图，不再停在上一屏。

## 3b. 第四轮新增的验收点（2026-11-08 晚）

1. **会议等待期有进度卡**：发起真实会议后，信息流出现「会议进行中」卡：四阶段步进（独立提案 → 交叉批判 → Condorcet 投票 → 主 Bot 决策）随真实阶段点亮、耗时走字、参与模型名单可见。
2. **放弃等待是诚实的**：点「放弃等待」→ 卡片换成说明（会议可能仍在后台运行并写盘）→ 输入区解锁（可以写补充约束、开新会议）→ 状态栏「已停止等待」。文案不出现「已取消会议」——后端没有 abort 接口，不说取消了。
3. **后台完成的会议不丢**：放弃后等会议跑完 → 状态栏「后台会议已完成 · 顶栏『决策书』可查看」→「决策书」按钮点亮 → 会话列表出现这条记录（meta 标注「决议（后台完成）」）。
4. **放弃后立刻开新会，旧结果不串台**：旧循环静默记录，不把旧提案/决议写进新会话的 feed。
5. **Ctrl+N 不再被浮层压住**：模型面板/提供商面板开着时按 Ctrl+N，浮层先关闭再出现新会议弹窗。
6. **会议运行中点「开始会议」有反馈**：提示「已有一场会议在等待结果…」，不是无声失败。
7. **插话提示 4 秒复位**：发送插话后 `Ctrl + Enter 发送 · 默认不插话也能跑完` 的常驻指引会自动回来。
8. **逐模型计数**（补遗）：会议运行中进度卡各阶段显示 `N/M` 计数（如「独立提案 1/2」），随每个模型调用完成（含失败）实时递增。
9. **插件页零等待**（补遗）：启动后空闲几秒目录已在后台载入；第一次点开「插件市场」即刻渲染，无读取等待。
10. **旧版服务拦截**（补遗）：若有旧版本面板服务占着端口，Edge 回退启动会报错「held by an older MeetingBot panel」并给出进程 PID，而不是让旧界面冒充新版本。
11. **后台失败也有下一步**（补遗 2）：放弃等待后会议失败 → 信息流出现「这场会议没能完成」轻提示，点名失败阶段与模型（来自引擎真实错误），给「重试本次任务」「换模型再试」两个真按钮；状态栏「后台会议未完成 · 可重试或换模型」；英文内部错误只放在次要的「技术细节」行。零 token 复验：`node tests/e2e/round4-failure.mjs <cdpPort>`（只桩住两个会议接口，不调用任何模型）。
12. **预取后插件介绍仍带省略号**（补遗 2）：启动后先不点插件页，等空闲预取完成，再打开「插件市场」→ 长介绍仍被截成三行并以「…」收尾，不是被 CSS 硬切一半；实测 `scrollHeight <= clientHeight + 1`。这是空闲预取引入过的一次回归，现在由 `clampLines()` 保存原文 + 视图显示后重钳制保证。
13. **E2E 判据是真实的**：插件三行裁剪同时检查 CSS（`overflow:hidden`、容器 ≤3 行）、真实截断（内容高度 ≤ 容器高度）与省略号；提示行复位用轮询等待而非固定 4.6 秒（后台窗口定时器会被节流）。此前用 `scrollHeight <= clientHeight` 判断在视图隐藏时恒为真的假阳性已修正。

## 5. 键盘与可达性

- `Tab` 能走遍所有按钮，`focus-visible` 轮廓清晰；每个按钮有可读名称。
- `Ctrl/Cmd + N` 打开新会议；中文输入法组字期间按 `Enter` 不误发；`Shift + Enter` 换行。
- `Esc` 依次关闭：自定义弹层 → 模型 / 提供商面板 → 插件详情 → 会话菜单；弹层打开时不会在背后叠开第二个弹层。
- 危险操作只确认一次；可撤销操作给「撤销 / 归档恢复」，不叠加确认框。
- 开启「动效减弱」后过渡动画确实停止。

## 6. 安全边界（不能被 UI 绕过）

- 默认是 `read-only`；界面改权限前先经过后端校验，提升高风险模式必须同意免责。
- 运行目录只允许应用目录下的相对文件夹名；`..`、绝对路径、盘符路径一律被拒。
- 「打开数据目录 / 审计日志」走 Electron 白名单，不能打开任意路径。
- 控制文件保护、路径边界、Python 沙箱、审计日志不受外观设置影响。
- 导出设置文件、日志、文档里不出现用户密钥、本机绝对路径或真实会话内容。
